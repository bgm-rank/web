# Bangumi 新番排行榜

基于 [Bangumi](https://bgm.tv) 数据的季度番剧排名展示网站。

**Live:** [rinshankaiho.fun](https://www.rinshankaiho.fun)

## Tech Stack

- Astro 5.x (SSG)
- Tailwind CSS v4
- TypeScript

## Development

```bash
pnpm install
pnpm dev       # localhost:4321
```

## Build

```bash
pnpm build     # output to ./dist/
pnpm preview   # preview production build
```
